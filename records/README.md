# Keep PHX Galactic Records

Two distinct collections:

1. **French Elevator Music Library** — current generic production music series, organized by volumes and moods.
2. **The Melodrama Archives** — future original theatrical/radio-drama recordings and story-linked scores.

Use catalog identifiers such as KPGR-FEM-001 and KPGR-MDA-001. Record release dates, credits, artwork, rights, and distributor links only when verified. No releases are asserted by this repository.
