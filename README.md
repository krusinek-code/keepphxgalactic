# Keep PHX Galactic

**Stay curious. Find your strange.**

A living creative field guide to Phoenix: unusual places, artists, folklore, original stories, physical artifacts, and music.

## Editorial categories
- **Locations:** interesting places and experiences, not a business directory
- **Artists:** local musicians, visual artists, and collaborators
- **Lore:** researched local legends and clearly labeled original fiction
- **Things:** curiosities, installations, objects, and discoveries

## Formats
Field Report · Midnight File · Artist Signal · Object Found · The Transmission · Strange Encounters · The Unidentified Object.

## Music imprint
**Keep PHX Galactic Records** includes the current **French Elevator Music Library** (generic production music, volumes) and the future **Melodrama Archives** (theatrical radio scores and original story soundtracks).

## Editorial principles
Document sources; distinguish observation from historical verification; label fiction; credit contributors and obtain reuse permission; link related records by stable IDs. Content-first: no website build required.
